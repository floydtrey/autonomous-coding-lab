# Worker Lab instructions

Read `docs/START_HERE.md` before acting.

Worker Lab is the protected learning/evaluation platform. Coding workers may implement exact bounded modules and exercise applications, but may not modify evaluator expectations, security policy, test selection, evidence integrity, approved-pattern promotion, or graduation requirements for their current attempt.

Do not copy execution-security logic from `autonomous-worker-framework` or product source from a consumer repository. Use explicit contracts between repositories.

Run only the numbered test profile relevant to the current change during development. Run the full active suite at a Phase 1 milestone.
