# Autonomous Worker Framework instructions

Read `docs/START_HERE.md` before acting. It is the routing and authority index for this repository.

Do not load every document by default. Follow the task-specific route in `START_HERE.md`, verify current Git state, and read only the active documents required for the task.

Core rules:

- Treat repository documents as maintained context, not as a substitute for current user instructions or Git evidence.
- `docs/CURRENT_STATE.md` describes the active checkpoint and next boundary.
- `docs/DECISIONS.md` contains durable active decisions; entries remain active unless explicitly marked superseded.
- Historical evidence and prior results do not grant current authority.
- Stop if active documents conflict, appear stale, or disagree with repository identity.
- Update `CURRENT_STATE.md` at capability/milestone changes and update the router when document responsibilities change.
