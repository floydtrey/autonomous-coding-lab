# Local Model Agent Research

Collect evidence about current open/local models used for:
- coding;
- planning;
- tool use;
- structured output;
- diagnosis/review;
- long context;
- vision/intent recognition where relevant to Vera.

Prioritize real agent runs and issue reports over leaderboard scores. Record runtime/backend, quantization, context size, tool format, hardware, success/failure pattern, and whether the model follows harness contracts reliably.
