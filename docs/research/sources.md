# Source Map

This file catalogs recurring places worth watching. Task 1 should expand and rank these rather than deeply researching individual projects.

## High-value source classes

### GitHub
Use repositories, issues, discussions, pull requests, release notes, and maintainer activity to find actual implementation decisions and failure reports.

Initial project families to discover and verify include:
- OpenHands
- SWE-agent
- Aider
- Cline
- LangGraph
- AutoGen
- CrewAI
- LlamaIndex agent/memory components
- local-model runtimes and agent integrations around Ollama and llama.cpp

### Security standards and incident sources
- OWASP AI Agent Security Cheat Sheet
- OWASP Agentic Application security work
- OWASP Agent Memory Guard
- MITRE ATLAS
- NIST AI risk/security guidance

Current OWASP guidance highlights prompt injection, tool abuse, privilege escalation, data exfiltration, memory poisoning, goal hijacking, excessive autonomy, approval manipulation, cascading multi-agent failures, and supply-chain risk as core agent concerns.

### Community / practitioner sources
Use these to discover recurring operational pain, then verify important claims against primary sources:
- Reddit communities focused on LocalLLaMA and AI agents
- Hacker News
- Hugging Face discussions/model cards
- framework/project Discords or forums when publicly searchable
- technical blogs and postmortems from developers running long-lived agents

### Research
Track relevant arXiv papers, benchmark/evaluation work, long-horizon agent evaluation, memory systems, tool-use reliability, and multi-agent coordination.

## Research rule
A source belongs on the watchlist because it produces recurring signal, not because it has one useful article.
