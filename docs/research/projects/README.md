# Project Deep Dives

One project per file. Do not research multiple projects in a single deep-dive task.

Suggested template:
- Project and repository
- Current activity
- Purpose
- Architecture
- Harness/tool model
- State/checkpoint/recovery model
- Validation/evaluation
- Security/permissions
- Local-model support
- Known failures/issues
- Reusable components/ideas
- Things ACL should avoid
- Collaboration/health assessment
- Sources
