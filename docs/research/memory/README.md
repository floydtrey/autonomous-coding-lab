# Memory and Persistent-Agent Research

Study implementations of:
- episodic memory;
- semantic/user-profile memory;
- working/context memory;
- retrieval and ranking;
- confidence/provenance;
- correction and forgetting;
- retention policies;
- memory integrity and poisoning defenses;
- separation of user-supplied history from system-verified history.

For future Vera work, prioritize architectures where the base model remains replaceable and personal memory remains inspectable, correctable, and separately protected.
