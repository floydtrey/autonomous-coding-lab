# Security Research

Priority topics:
- direct and indirect prompt injection;
- tool misuse and privilege escalation;
- credential and data exfiltration;
- memory/context poisoning;
- goal hijacking;
- excessive autonomy and approval bypass;
- multi-agent cascading failures;
- unsafe MCP/tool integrations;
- sandbox escape and arbitrary command execution;
- supply-chain risk;
- auditability, rollback, and fail-closed design.

Initial public guidance from OWASP strongly supports ACL's existing separation of model output, authorization, execution, and independent validation. Research should look for concrete failures and mitigations rather than collecting generic security advice.
