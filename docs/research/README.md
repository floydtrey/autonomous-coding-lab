# Autonomous Coding Lab Research Campaign

This branch is a research-only workspace for studying existing agent systems before ACL recreates solved problems or repeats known failures.

## Scope

Research topics include:
- autonomous coding agents and coding harnesses;
- local-model agent compatibility;
- tool use and structured output;
- long-running agent runtimes, checkpoints, recovery, and observability;
- multi-agent orchestration and routing;
- sandboxing, permissions, least privilege, and secret handling;
- prompt injection, memory poisoning, goal hijacking, and tool abuse;
- persistent memory and user-model architectures relevant to future Vera work;
- active projects, maintainers, communities, and possible collaboration targets.

## Operating rule

Work one research task at a time. Read `RESEARCH_STATE.md` first. Do not begin future phases to conserve effort or pre-summarize later work. Save evidence and sources, update the catalog/state, commit the research-only changes, and stop.

This branch must not modify ACL runtime code or authorize worker/model execution.
