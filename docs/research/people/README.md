# People and Account Deep Dives

Use this directory only after the landscape and project watchlist are established.

For each person/account, capture:
- role/project affiliation;
- recent activity;
- recurring technical themes;
- repositories/posts/talks;
- relevant lessons;
- whether their work is close enough to ACL/Vera to monitor or contact.

Do not collect unnecessary personal information. Focus on public technical work relevant to the project.
